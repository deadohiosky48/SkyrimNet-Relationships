# Romantasy Stub

An empty plugin named `CS_Romantasy.esp`: a 66-byte file header and nothing
else - no records, no scripts, nothing taken from Romantasy.

**Who it is for:** players who upgraded from Relationships 1.x, had their bonds
brought over, and now want Romantasy gone. Saves made while Romantasy was
installed still list its plugin and may refuse to load without it; this stands
in for it so they load.

- Enable it in place of Romantasy, never beside it.
- Keep it enabled for as long as you play saves that needed it.
- Flagged as a light plugin, as Romantasy's own plugin is.

Released as a separate download, `Romantasy Stub.zip`, containing only
`CS_Romantasy.esp`.
