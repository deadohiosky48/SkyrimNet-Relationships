# MARAS Stub

Two empty plugins named `TT_MARAS.esp` and `TT_Maras_OStim.esp`: a 66-byte
file header each and nothing else - no records, no scripts, nothing taken from
MARAS.

**Who it is for:** players who had their marriages brought over into
Relationships (the dashboard's Playthrough repairs, "Import MARAS marriages")
and now want MARAS gone. Saves made while MARAS was installed still list its
plugins and may refuse to load without them; these stand in for them so they
load.

- Import first, with MARAS still installed. Once MARAS is gone, there is
  nothing left to import from.
- Enable these in place of MARAS and its OStim patch, never beside them.
- Keep them enabled for as long as you play saves that needed them.
- Flagged as light plugins, as MARAS's own plugins are.
